# HIMALAYAN KITCHEN 🏔️🍜

> **A high-sensory, cinematic 3D digital experience for Himalayan Kitchen.**  
> Crafted with React 19, TypeScript, Three.js / React Three Fiber, Tailwind CSS, and Web Audio API.

---

## 🌟 Overview

**Himalayan Kitchen** is an experimental, award-winning restaurant web experience celebrating high-altitude gastronomy from the Sagarmatha / Everest region. It blends ancient fire hearth traditions with high-modern culinary art across three dialectic menus:
- **Modified Nepali**: Foraged Morel & Truffle Momo
- **Tangra Wok**: 800°C Wok-Scorched Wild Tiger Prawns
- **High-Altitude Botanical**: Smoked Himalayan Juniper Elixirs

---

## ✨ Key Features

- **Procedural 3D Alpine Ridge & Glacial River**:
  - Multi-octave faceted low-poly mountains with dynamic alpenglow and alpen-shadow contrasts.
  - Interactive canyon cleft that parts organically on scroll to reveal a flowing glacial meltwater river with dynamic rapids foam.
- **Cinematic Dual-Stage Hero**:
  - Stage 01: Low-angle monumental towering summit view.
  - Stage 02: Mountain canyon opening, descending into the sacred hearth and gastronomic altar.
- **Interactive 3D Culinary Artifact**:
  - Live rotating 3D slate pedestal with smoking wood chips, foraged botanicals, and culinary dossier inspection.
- **Dual Aesthetic Themes**:
  - **Light Mode**: Crisp alpine daylight, sandstone canyon floor, and cyan glacial waters.
  - **Dark Mode**: Midnight summit moonlight, deep obsidian voids, and glowing embers.
- **Synthesized Alpine Soundscape**:
  - Pure Web Audio API procedural sound engine with howling mountain winds, crackling cedarwood fire, and flowing glacial river currents.
- **Curated Sensory Storytelling**:
  - Interactive tasting lab matrix, botanical altitude passports, chapter-by-chapter scroll expedition, reservation concierge, and contact portals.

---

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript, Vite
- **3D Engine**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Styling**: Tailwind CSS, Lucide Icons
- **Animation & Motion**: Smooth scroll via Lenis, custom GLSL/Three.js frame loops
- **Audio**: Web Audio API (procedural synthesis)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Hpshiva/himalayan-kitchen.git

# Navigate into project directory
cd himalayan-kitchen

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
